mez.run secure DNS

This page installs the private AdGuard Home DNS-over-HTTPS profile for the corgi-justice Tailscale network.

Apple devices

Install Tailscale first and connect to the tailnet. Then open this link in Safari:

Install the private DNS profile

Approve it in Device Management. Remove it there if you no longer want the profile.

Browsers

For a browser custom DoH setting, use:

https://dns.corgi-justice.ts.net/dns-query

The browser must be connected to Tailscale. A browser-specific DNS setting can override the system profile.
